# Central OCR & Product Intelligence API\n\nA local-first FastAPI MVP for OCR, product intelligence, inventory, billing, audit logging, and new-product approval.\n\n## Quick start\n\nThe application source is inside the central_product_api/ directory.\n\n    git clone https://github.com/param3026/central-ocr-product-intelligence-api.git\n    cd central-ocr-product-intelligence-api/central_product_api\n    python3 -m venv .venv\n    source .venv/bin/activate\n    python -m pip install --upgrade pip\n    pip install -r requirements.txt\n\nInstall OCR and barcode system tools:\n\n    # macOS\n    brew install tesseract zbar\n\n    # Debian/Ubuntu\n    sudo apt-get update\n    sudo apt-get install -y tesseract-ocr libzbar0\n\nStart PostgreSQL, apply migrations, seed demo data, and run the API:\n\n    docker compose up -d db\n    alembic upgrade head\n    python seed.py\n    uvicorn app.main:app --reload\n\nOpen http://127.0.0.1:8000/docs for interactive API documentation.\n\n## Validation\n\nRun the tests from central_product_api/:\n\n    pytest -q\n\nThe suite covers authentication, product master behavior, duplicate prevention, matching, inventory, billing, upload validation, invoice approval/idempotency, invoice response fields, and product-suggestion approval/rejection.\n\n## Demo credentials\n\nThe seed script creates client demo-pos with development secret change-me-in-development. Exchange them at POST /api/auth/token, then use the returned bearer token for protected endpoints.\n\n## Scope and handoff summary\n\nAvailable: PostgreSQL-backed API, product master, matching, invoice OCR foundation, image OCR and barcode providers, document analysis, inventory, billing, audit logging, and API-based product approval.\n\nUpdated: setup instructions, dependencies, OCR/barcode installation, Alembic migration support, endpoint documentation, tests, status notes, and future-work boundaries.\n\nThe delivered repository is a tested MVP ready for local demonstration and future ERP/POS integration. See central_product_api/README.md for the complete endpoint reference and limitations.
